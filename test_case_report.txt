# Test Cases for Simple Shell Implementation

## Overview
The following test cases were created to verify that the shell meets the project requirements for command execution, built-in commands, process management, redirection, piping, signal handling, interactive mode, batch mode, and error handling.

Test Case 1: Basic Command Execution
Input: pwd
Expected Output: current directory is displayed
Actual Output: /mnt/c/Users/Owner/VS_CODE/systems-shell
Result: Pass

Test Case 2: Built-in cd
Input: cd ..
Expected Output: directory changes successfully
Actual Output: /mnt/c/Users/Owner/VS_CODE$
Result: Pass

Test Case 3: Invalid cd
Input: cd fakefolder
Expected Output: error message is displayed and shell keeps running
Actual Output: failed to change directories: No such file or directory
Result: Pass

Test Case 4: Built-in help
Input: help
Expected Output: help information is displayed
Actual Output: 
Built-in commands:
  cd <dir>   Change current directory
  help       Show this help message
  exit       Exit the shell
Features:
  command execution
  input redirection with <
  output redirection with >
  piping with |
  background execution with &
  Ctrl+C and Ctrl+Z signal forwarding
Result: Pass

Test Case 5: Built-in exit
Input: exit
Expected Output: shell exits successfully
Actual Output: Thank you for using the shell!
Result: Pass

Test Case 7: Input Redirection
